# 💀 DOOM Online — P2P Multiplayer Deathmatch

Онлайн-версия легендарной игры **DOOM (1993)**, работающая прямо в веб-браузере без установки и плагинов, с поддержкой **мультиплеера по ссылке (P2P)** в классическом формате **Deathmatch** (как в Quake и оригинальном Doom).

🔗 **Сыграть онлайн (GitHub Pages):**  
👉 **[https://shozprog.github.io/doom-online/](https://shozprog.github.io/doom-online/)**

---

## 🎮 Возможности

- **🌐 Мультиплеер по ссылке через WebRTC P2P:**
  - Создание собственного лобби в 1 клик.
  - Генерация уникального кода комнаты и готовой ссылки приглашения (например, `?room=DM-4821`).
  - Удобная кнопка **«📋 Скопировать ссылку для друзей»**.
  - Прямое P2P-подключение через WebRTC DataChannels с обходом NAT через публичные STUN-серверы Google и Cloudflare (работает через интернет, не требует нахождения в одной локальной сети).
  - В лобби хост видит список подключившихся игроков, цвет их персонажей и живой пинг.
  - При нажатии **«НАЧАТЬ ИГРУ»** все подключенные игроки одновременно переносятся на карту матча!

- **☠ Формат Deathmatch (в стиле Quake):**
  - Поддержка режимов **Deathmatch 1** (*Weapons Stay*) и **Deathmatch 2** (*Items Respawn*).
  - Таблица фрагов и пинга в реальном времени (по нажатию `Tab`).
  - Мгновенный респаун на точках появления Deathmatch.
  - Настройка лимита фрагов (10, 20, 30, 50 или без лимита) и времени.
  - Возможность включения или отключения монстров.
  - Все ключи выдаются сразу, позволяя свободно перемещаться по всей карте.

- **📦 Оригинальные ассеты DOOM (Shareware Episode 1):**
  - Официальный shareware-эпизод **DOOM1.WAD** (v1.9, *Knee-Deep in the Dead*) встроен в репозиторий.
  - 9 уровней: `E1M1: Hangar`, `E1M2: Nuclear Plant`, `E1M3: Toxin Refinery`, `E1M4: Command Control`, `E1M5: Phobos Lab`, `E1M6: Central Processing`, `E1M7: Computer Station`, `E1M8: Phobos Anomaly`, `E1M9: Military Base`.
  - Оригинальное оружие: кастет, бензопила, пистолет, дробовик, пулемет, ракетница, плазмоган.
  - Аутентичные звуковые эффекты и классический саундтрек Бобби Принса через встроенный OPL3/AdLib синтезатор.
  - Автоматическая загрузка WAD при первом запуске — ничего не нужно искать и скачивать вручную!

- **⚡ Чистый WebGL и JavaScript:**
  - Работает на всех современных браузерах (Chrome, Firefox, Edge, Safari, мобильные браузеры).
  - Плавные 60 FPS, поддержка мыши (Pointer Lock), клавиатуры, геймпадов и сенсорных экранов.

## 🕹 Управление

| Клавиатура / Мышь | Действие |
|---|---|
| **W, A, S, D** | Передвижение / стрейф |
| **Мышь** (клик по экрану для захвата) | Обзор / прицеливание |
| **ЛКМ** или **Q** | Выстрел |
| **Пробел** | Прыжок / Респаун после смерти |
| **E** | Использовать (открыть дверь, нажать кнопку, лифт) |
| **1 — 7** / Колесико мыши | Смена оружия |
| **Left Shift** | Бег |
| **C** | Приседание |
| **Tab** | Таблица счета / фрагов |
| **Esc** | Меню паузы |

## 🚀 Как начать игру с друзьями

1. Откройте ссылку: **[https://shozprog.github.io/doom-online/](https://shozprog.github.io/doom-online/)**
2. В главном меню выберите **Мультиплеер (P2P)**.
3. Нажмите **☠ Создать лобби Deathmatch**.
4. Выберите уровень (например, `E1M1: Hangar`) и настройки матча.
5. В открывшемся лобби нажмите **«📋 Скопировать ссылку для друзей»** и отправьте ее в Discord, Telegram или любой чат.
6. Друзья переходят по ссылке и автоматически подключаются прямо в ваше лобби через WebRTC P2P!
7. Когда вы увидите всех игроков в списке, нажмите **«НАЧАТЬ ИГРУ»**!

## 🛠 Технический стек

- **Движок**: WebGL 3D JavaScript Doom Engine (на базе открытой реализации `spipu/doom-js`).
- **Сетевой стек**: WebRTC DataChannels + STUN (`stun:stun.l.google.com:19302`, `stun:stun.cloudflare.com:3478`).
- **Сигналинг**: Легковесный MQTT 3.1.1 over WebSockets (HiveMQ / EMQX public brokers, без выделенного сервера).
- **Синтез аудио**: `libadlmidi` WebAssembly (эмуляция OPL3 FM-синтезатора).
- **Хостинг**: GitHub Pages (автоматический деплой через GitHub Actions).
